# Handoff flows

Flows that need both apps on one emulator: Field Log exports a `.homerecord` and House Manual imports it (walkthrough F10 → H18, AC-F51, AC-H17, AC-C46, AC-C47). The device suite installs both apps for this folder. Flows arrive with PLAN T063; until then the stage reports "skip".

Naming: `X01-export-import.yaml`, `X02-claim-link.yaml`. The `X` prefix keeps them out of the per-app walkthrough tables.
