# HomeRecord

Two native Android apps on one shared "home record": **House Manual** gives homeowners a breaker panel map, a shutoff map with an emergency screen, one-person circuit mapping and an equipment record; **Field Log** gives small contractors fast photo, note and voice capture on the job, behind-the-wall photos, a daily report PDF and a close-out handoff that House Manual imports so the homeowner starts with a pre-filled record. Everything runs on-device with no accounts. Kotlin, Jetpack Compose, Material 3, Room.
